# PLEASE public analysis release v1.4.0

PLEASE is the PLant Evidence Atlas for StrEss. This directory contains the
versioned public analysis layers used by the interactive resource.

Start with:

- `DATA_DICTIONARY.md` for file-level and ontology definitions;
- `statistical_contract.md` for estimands, null references and interpretation
  boundaries;
- `study_source_index.tsv` for official repository accessions and links;
- `study_families.tsv` for the 62 dependency-resolved study families;
- `PLEASE_complete_analysis_release_v1.4.0.zip` for one-file download of all
  derived analysis layers.

The release contains 71 standardized published conclusions, 2,543 testable
biological statements, 7,306 audited evidence records, 27,000 analytical
specifications, 54,000 exact method-level effects and 88,789 broad route-level
records. The analytical layers remain nested within 57 study families eligible
for primary inference.

Original expression matrices and sequence data remain at their official public
repositories and are not redistributed here. Every study family has at least
one official source link in `study_source_index.tsv`.

SHA-256 values for individual files are shown on the Methods and downloads page
and in the site-level `release-manifest.json`.
