# PLEASE release validation

Release: 1.4.0  
Validated: 4 September 2026  
Search boundary date: 27 August 2026

## Data integrity

- 62 dependency-resolved study families are catalogued; 57 meet the
  primary-inference criteria.
- The public tables contain 71 standardized published conclusions, 2,543
  testable biological statements, 7,306 audited evidence records, 27,000
  analytical specifications, 54,000 exact method-level effects and 88,789
  broad route-level records.
- Stable identifiers are unique at their respective layers, and all links
  among studies, conclusions, statements and evidence records resolve.
- All compressed TSV streams pass decompression checks.
- The complete analysis archive contains 35 expected members and passes ZIP
  integrity testing.
- Every individual analysis download is covered by a size and SHA-256 check.

## Source links

- All 62 study families have at least one official repository accession.
- All 87 official data links returned HTTP 200 during release validation.
- All 51 DOI links resolved through the DOI service.
- Both institutional links returned HTTP 200.
- Original expression and sequence data remain in their official repositories;
  PLEASE provides direct source links rather than redistributing those files.

## Website checks

- All six application routes render at desktop and mobile viewport sizes.
- No script exceptions or page-level horizontal overflow were detected.
- Evidence tables, detail views and all 31 download links initialize correctly.
- All 11 image elements, representing 10 distinct asset files, load successfully.
- Public text and machine-readable files contain no generator attribution,
  prompt material, workstation paths or development-only field names.
- Raster assets used by the site contain no embedded software or prompt
  metadata.

## Scope boundary

This validation establishes technical integrity and deployment readiness. It
does not establish a known denominator for all public plant-stress evidence.
The approved article citation, persistent production URL, contact details and
reuse licence should be added by the project owners before archival deposition;
none has been invented in this package.
